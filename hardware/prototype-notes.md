## Design history supplied by the owner

The initial enclosure concept was a PETG cylinder with an 18650 cell near the bottom, module brackets, a secondary shelf, and a thermal air gap below solar-powered glass. The current concept is a smaller golf-tee shape with an EEMB 803465 flat LiPo pouch below the PCB in a double-decker arrangement. The charging circuit, capacity, fit, and thermal behavior of that revised layout have not been verified by this repository.

The enclosure concept includes a sealed four-wire passage using a cable gland or silicone plug and a recessed USB charging port. Fusion 360, Shapr3D, or Onshape are possible tools for the final model. A 30-minute telemetry interval is a design goal; the reference sketch currently polls every five seconds for bench inspection. No completed weatherproofing, battery-life, charging, or enclosure test is claimed.

The owner describes an ESP-NOW edge network with a Raspberry Pi manager and two caching tiers. Compute Module integration has also been considered. This is the intended network architecture; the current source uses USB serial and an HTTP bridge. No ESP-NOW gateway or durable cache is implemented here.

The owner reports that ERP patterns associated with JobProgress informed the proposed relational hierarchy, routing, and state machines. The small organization/device/reading schema in this repository is newly written. The supplied narrative does not include the earlier cloud implementation or a JobProgress integration.
